# W1 练习代码

FDE 训练第一周的练习集合。从零基础开始，每天一个产出。

## 文件说明

| 文件       | 内容      | 用到的知识                       |
| -------- | ------- | --------------------------- |
| hello.py | 第一个程序   | print、变量                    |
| types.py | 类型与运算符  | int / str / float、类型转换      |
| ex1.py   | 基础综合练习  | 变量、f-string、for 循环、类型转换     |
| ex2.py   | 列表与字典练习 | list、dict、list 套 dict、格式化输出 |
| ex3.py   | 成绩报表生成器 | 单次遍历、if/elif、打擂台找最值、报表对齐    |

## ex3：成绩报表生成器

输入一组学生成绩，输出带统计的报表：

- 逐个学生判断等级（优秀 / 及格 / 不及格）
- **单次遍历**同时算出：总分、平均分、最高分、最低分、及格率
- 报表对齐输出

运行：

```
python ex3.py
```

## 验证过的边界情况

- 打乱数据顺序后，最高分与最低分仍然正确    
  （曾在这里发现一个 `elif` 误用的潜伏 bug：最小值恰好排在最后时不会暴露）
