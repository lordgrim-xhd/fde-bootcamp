## ex3：成绩报表生成器

输入一组学生成绩，输出带统计的报表。

### 结构

| 函数                              | 职责                  |
| ------------------------------- | ------------------- |
| `get_level(score)`              | 分数 → 等级（优秀/及格/不及格）  |
| `analyze(students)`             | 单次遍历，返回所有统计数字（dict） |
| `print_report(students, stats)` | 只负责显示，不含任何计算        |

主程序只有两行：`stats = analyze(students)` → `print_report(students, stats)`

### 设计原则

- **算的不管显示**：`analyze` 里没有任何 `print`
- **显示的不管算**：`print_report` 里没有任何统计逻辑
- **逻辑只存在一份**：等级判断只在 `get_level` 里

### 验证过的边界

- 打乱数据顺序后，最高/最低分仍然正确
- 曾发现 `elif` 误用导致最小值算错（最小值恰好排最后时不暴露）
